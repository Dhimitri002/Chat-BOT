## 🔄 Ciclo de Vida da Assinatura

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│  Trial   │───▶│  Ativa   │───▶│  Past    │───▶│ Cancelada│
│  (7 dias)│    │          │    │  Due     │    │          │
└──────────┘    └──────────┘    └──────────┘    └──────────┘
                     │               │
                     │               │
                     ▼               ▼
              ┌──────────┐    ┌──────────┐
              │ Suspensa │    │  Expirada│
              │          │    │          │
              └──────────┘    └──────────┘
```

### Status da Assinatura

| Status | Descrição | Acesso |
|---|---|---|
| **Trial** | 7 dias grátis | Total |
| **Active** | Pagamento em dia | Total |
| **Past Due** | Pagamento atrasado | Limitado (somente leitura) |
| **Suspended** | Suspensa por admin | Bloqueado |
| **Cancelled** | Cancelada pelo usuário | Bloqueado |
| **Expired** | Expirada | Bloqueado |

## 🔄 Upgrade e Downgrade

### Upgrade
- Imediato
- Diferença proporcional cobrada
- Novos limites aplicados instantaneamente

### Downgrade
- Aplica no próximo ciclo de cobrança
- Dados mantidos por 30 dias
- Se exceder limites do novo plano, bot é pausado
