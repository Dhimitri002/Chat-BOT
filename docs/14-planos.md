## Descrição de Cada Plano

### 🥉 Starter — "Seu primeiro bot"
Para quem quer testar um bot simples no WhatsApp. Respostas programadas, sem IA. Ideal para cardápio, FAQ básico, saudações.

### 🥈 Basic — "Mais poder"
Para pequenos negócios que precisam de mais intenções e comandos. Relatórios básicos para acompanhar o uso.

### 🥇 Plus — "Profissional"
Para negócios que querem personalização avançada, arquivos, webhooks e mais capacidade. Ponto de entrada para automação.

### 💎 Pro — "Inteligente"
O primeiro plano com IA real. Inclui LLM (Groq) para respostas naturais, Flora AI como assistente, memória de conversa e processamento de PDF/imagem.

### 👑 Master — "Poder máximo"
Para negócios que precisam do melhor. LLM forte (GPT-4o), memória longa, áudio, transcrição, automações e suporte prioritário.

### 🏆 Elite — "Negócio sério"
Para empresas que precisam de analytics avançado, multi-LLM, API access, white-label parcial e campanhas.

### 🏢 Enterprise — "Sob medida"
Para grandes operações. White-label total, SLA garantido, suporte dedicado, multiusuário, integrações corporativas e tudo ilimitado.

## Estratégia de Preços

```
Anual vs Mensal:
  - Anual: 15-20% de desconto (equivale a ~2 meses grátis)
  - Exemplo Pro: R$199,90/mês → R$1.999/ano (economia de R$399)

Trial:
  - 7 dias grátis em qualquer plano
  - Sem cartão de crédito
  - Limite de 100 mensagens no trial

Upgrade/Downgrade:
  - Upgrade: imediato, paga proporcional
  - Downgrade: no próximo ciclo, mantém recursos até lá

Grace period:
  - 3 dias após vencimento
  - Bot continua funcionando com avisos
  - Após 3 dias: bot pausado (não deletado)
  - Após 30 dias: dados arquivados (recuperável em 90 dias)
```
